Counter Arena 3D — نسخه PHP برای jamprogrammer.ir/conter/

نصب:
1) محتوای ZIP را در public_html هاست استخراج کنید.
2) ساختار نهایی باید به این صورت باشد:
   public_html/conter/index.php
   public_html/conter/api.php
   public_html/conter/.htaccess
   public_html/data/.htaccess
   (فایل‌های users.json و rooms.json در اولین درخواست API به‌صورت خودکار ساخته می‌شوند.)
3) PHP 8.1 یا بالاتر و افزونه JSON فعال باشد.
4) پوشه data برای PHP قابل‌نوشتن باشد. مجوز 777 ندهید؛ از مالکیت/مجوز مناسب هاست استفاده کنید.
5) دامنه باید HTTPS داشته باشد.
6) باز کنید: https://jamprogrammer.ir/conter/

ویژگی‌های این نسخه:
- در شروع، پنل ورود/ثبت‌نام نشان داده می‌شود؛ گزینه بازی آفلاین بدون حساب هم موجود است.
- حساب‌ها در data/users.json ذخیره می‌شوند و رمز عبور به‌صورت هش نگهداری می‌شود. فایل‌های داده عمداً در ZIP قرار نگرفته‌اند تا با نصب نسخه جدید، کاربران و اتاق‌های قبلی پاک نشوند.
- فهرست کاربران ثبت‌نام‌شده و وضعیت آنلاین تقریبی برای کاربران واردشده نمایش داده می‌شود.
- اتاق‌های عمومی در فهرست همه کاربران واردشده دیده می‌شوند؛ اتاق خصوصی از فهرست عمومی مخفی است و با کد دعوت قابل ورود است.
- تنظیم نقشه، حالت بازی، ظرفیت، خصوصی/عمومی بودن و تعداد بات‌ها وجود دارد.
- تنظیمات اتاق و عضویت‌ها در data/rooms.json ذخیره می‌شود.

محدودیت مهم:
این نسخه همچنان نمونه اولیه چندنفره با همگام‌سازی HTTP polling است. موقعیت بازیکنان و فهرست لابی همگام می‌شود، اما سیستم رقابتی کامل با سرور authoritative برای تیراندازی، آسیب، برخوردها و هوش مصنوعی بات‌های آنلاین نیست. گزینه بات فعلاً در تنظیمات/فهرست اتاق ثبت می‌شود؛ برای بات‌های واقعی که در میدان نبرد حرکت و شلیک کنند، باید منطق AI و وضعیت بازی سمت سرور توسعه داده شود. بازی 3D از CDN برای Three.js استفاده می‌کند و برای بارگذاری آن اینترنت لازم است.
